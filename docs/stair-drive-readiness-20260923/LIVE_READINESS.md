# 현재 주행 준비 상태

> 2026-09-23 최신 수정·실주행 결과: [현재 개발 상태](../development-status-20260923.md). 아래 기존 설명과 시점별 관측 기록은 해당 당시 범위로 해석하세요.


운영 설정의 기본값은 **LiDAR control, configured=true, observe_only=false, 자동 BAG 기록**이다. 설정 파일은 `config.env`가 지정하는 `stair_lidar_3f_4f_test.yaml`이다. 관측용 일반 파일 `stair_lidar.yaml`의 false 값을 그대로 읽는 실행 경로는 사용하지 않는다.

이번 변경은 실행 스크립트·환경 설정·시작 전 검사·관련 시험과 문서에만 적용한다. ROS 노드 소스, launch 구성, 메시지와 action, 기존 LiDAR 추적과 경로 치수는 변경하지 않는다. 기존 시험 클라이언트도 상시 launch에 추가하지 않는다.

추가로 기존 실행 스크립트의 종료 신호 뒤 기동 재개 가능성, 원격 센서 검사/세션 생성 실패가 성공으로 덮이는 문제, 수동 기록 수신기의 원격 HOME 해석을 수정했다. 모두 로컬 mock 실행으로 실패 전달을 확인했다. **OBSERVED · S2/M3**이며 하드웨어에 명령을 보낸 시험은 아니다.

검증은 전체 bundle/운영 사이트 검사, 새 터미널 환경의 run.sh --check, 실행 스크립트 및 노드 경계 회귀 시험, 실제 launch 인자 해석으로 확인한다. [최종 결과](evidence/live-readiness.json).

## 주행 검증 범위

기존 제어 코드와 실제 시험 설정을 사용한 이상적 운동 모델에서 중심 배치, 횡방향 3cm, 방향 3도 조건은 모든 계단 단계를 통과했다. 이는 설정된 경로와 상태 전환의 자기 모순을 찾는 소프트웨어 검사다. 완벽한 측위·즉시 속도 응답·단순화한 높이를 가정하므로 실제 성공률, 균형 유지, 계산 지연의 증거가 아니다. 검증 방법과 결과는 JSON에 구분해 기록한다.

`configured=true`는 제어 설정을 읽을 수 있다는 뜻이다. `commissioned=false` 경로는 기존 명시적 단계 시험으로 실행하며, `/mission`의 정상 층간 임무로는 아직 승인되지 않았다. 해당 값을 근거 없이 true로 바꾸거나 완료 판정을 위조하지 않는다. [첫 계단/회전/상부 진출 시험 명령](RUNBOOK.md).

2026-09-23 08:18 KST 실장비 점검에서 미니PC와 TRON 연결을 확인했고, 남아 있던 9월 21일 유휴 세션을 정리한 뒤 기존 스택을 재실행했다. 실제 시작 검사가 READY를 출력했으며 Supervisor=NAV/connected, FloorState=3F/READY, LiDAR=control/TRACKED다. 설정 hash가 configured=true 파일과 일치한다. 자동 BAG는 `logs/20260923_081522/`에 기록 중이다. [실시간 점검 근거](evidence/live-health-20260923.json).

추가 점군 구독을 제외한 12초 측정에서 측위 결과 약 5Hz, 계산 시간 중앙값 77ms, 측정부터 결과 생성까지 중앙값 233ms/최대 298ms, 제어기가 가진 최신 측위의 나이 최대 483ms였다. 해당 구간의 dropped_scans/rejected_imu/worker_error는 0/0/없음이다. 관측 명령 스트림 약 40Hz에서 속도는 모두 0이고 활성 미션/NAV 목표도 없다. 이는 평지 대기 상태의 측정이며 계단 하중·회전·장시간 통신 지연까지 검증한 결과는 아니다.

현재 로봇은 사용자가 확인한 계단과 떨어진 평지에 있다. 실제 지도 위치·방향은 RViz에서 확인하고, 계단 시험은 지정 진입점 배치와 preview를 거쳐 시작한다. 자동 localization READY는 독립적으로 실제 지도 위치가 맞음을 입증하지 않는다. 계단 시험 및 정상 층간 미션 commissioning은 아직 수행하지 않았다.

**Safety verdict:** ROS 제어 소유자와 물리 동작 설정을 바꾸지 않았고 시작 전 검사 범위를 수정했다. 실제 계단에서의 자세 유지와 주행은 UNVERIFIED. **Mobility verdict:** 실제 센서/제어 스택의 기동과 control 설정 적용을 확인했다. 현재 유휴 대기이며 실제 3→4층 완주와 정상 미션 commissioning은 미완료다.
