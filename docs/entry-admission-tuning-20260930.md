# 5F→RF 진입 조건 조정 및 테스트 준비

2026-09-30. 적용 상태: 기존 스택 재시작 완료. 로봇 주행 명령은 전송하지 않음.

## 적용 내용

- 5F→RF 진입 정합 RMSE 한도 0.18→0.22m. 세 실패 BAG의 원본 입력 재현 최대 잔차 0.2045m를 바탕으로 한 현장 시험값이며 절대 위치 오차 한도가 아니다. 3F→4F 기준은 변경하지 않았다.
- 정합 후 새 정상 관측을 최대 1초 기다린다. 같은 epoch의 더 큰 sequence, 관측 나이 0~0.4초만 허용한다. 정합이 추적 작업자를 잠시 점유한 탓에 바로 0.5초 제한에 걸리던 경로를 개선했다. 측정 시각을 갱신하거나 오래된 위치를 새것처럼 사용하지 않는다.
- 후보를 점수순 정렬한 뒤 가까운 후보를 묶어 더 나은 해가 버려지는 일을 막는다. 서로 다른 해의 점수 차이 기준 0.05는 유지한다.
- 정합 부족, 뒤집힌 중력, 평면 투영 잔차, 서로 다른 후보 모호성을 실패 문구에서 구별한다.
- 상승·회전 속도, 전이 구조, 하드웨어 명령 방식, 센서 노드 구성은 변경하지 않았다.

## 검토와 보존

독립 cold read에서 시간 측정 순서와 timeout 경계 지적을 받아 수정했다. epoch는 대기 중, anchor 설치 시, 실제 prepare 시 각각 다시 검증한다. 검증 독립성 점검에서 동일 BAG으로 조정하고 통과율을 평가한 한계를 표시했다. 값의 canonical source는 운영 YAML이며, 이전 보고서 수치는 과거 기록이다. 근거 없는 이식성·완주 보장은 하지 않는다.

기존 worktree 변경은 유지했다. 이번 변경은 ros_lidar.py, 5F route YAML, 대기 회귀 검사, ROS adapter 검사, CMake 검사 등록이다. 원본 코드·설정의 변경 직전 사본과 분석 자료는 이 폴더에 남겼다. 임시 편집 스크립트는 제거했다. 정상 스택은 사용자 테스트를 위해 실행 상태로 유지한다.
