# UI 지도와 NAV 경로

기존 mission manager 콘솔에 읽기 전용 지도 표시를 추가했다. 제어 노드나 속도 발행자는 추가하지 않았고, 지도 클릭으로 목표를 보내는 기능은 이번 범위가 아니다.

표시: 현재 `/map`, 파란 전체 NAV 경로(`/move_base/NavfnROS/plan`), 주황 로컬 경로(`/move_base/TrajectoryPlannerROS/local_plan`), 초록 로봇 위치·방향(`map → base_Link` TF), 현재 move_base 목표점. 경로는 NAV 계획이며 실제 통과 궤적이나 계단 3D 추적 궤적이 아니다.

지도는 origin 위치·회전·resolution을 반영하고 ROS OccupancyGrid의 아래→위 행을 화면의 위→아래 행으로 변환한다. 경로가 odom 등 다른 frame이면 해당 Path header 시각의 TF로 map에 변환한다. TF가 없거나 frame이 섞이면 해당 경로를 숨기고 이유를 표시한다. 로봇 TF 나이 허용 범위는 -0.5~2초, 로컬 경로 수신 경과 한도는 3초다. 이 한도는 **표시만** 제어하며 주행을 중단하지 않는다.

전체 경로는 매초 재계획되지 않을 수 있으므로 나이만으로 지우지 않는다. 새 목표·일치하는 terminal·지도 revision 변경·층 상태 변경 때 이전 경로를 지운다. 층 READY가 아니거나 층 heartbeat가 2초 이상 지연되면 위치와 경로를 숨긴다. 층 전환 중 배경에는 마지막 지도가 남을 수 있으며 대기 문구를 표시한다. 전체·로컬 경로가 같은 순간에 생성된 것이므로 보장하지 않는다.

휠/± 확대·축소, 드래그 이동, 전체 보기, 크게 보기(fullscreen)를 지원한다. 전체 보기는 미관측 여백보다 실제 관측 영역을 중심으로 맞춘다. 지도 PNG는 revision이 바뀔 때만 `/api/map`에서 받아 캐시하고, 상태·위치·경로는 기존 약 1초 갱신을 사용한다. 정밀 실시간 제어 화면이나 RViz 전체 대체를 의미하지 않는다.

검증: 지도 인코딩/좌표/TF 부재/층 전환/종료 표시 테스트 및 기존 HTTP·주행·녹화 회귀 검사 통과. 미리보기에는 2026-09-21 문틀 BAG의 실제 지도·global plan·map frame 위치·목표를 넣고 녹화 기록임을 표시했다. 미리보기에는 해당 시점 local plan을 변환해서 넣지 않았다. 실시간 운영 스택은 재시작하지 않았으며 실제 센서 연결은 UNVERIFIED다.

실행 방법은 `console-recording-20260930.md`와 같다. 기존 스택 종료 후 `MISSION_CONSOLE_PORT=8765 STAIR_RECORD=0 ./run.sh`로 실행하고 같은 PC의 `http://127.0.0.1:8765`에서 확인한다. 지도·TF·NAV 토픽이 수신되면 표시된다. 지도만 보는 것으로 주행·녹화가 시작되지 않는다.
