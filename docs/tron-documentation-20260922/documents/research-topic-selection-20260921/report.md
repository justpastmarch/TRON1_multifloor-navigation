# TRON 학술제 연구 주제 선정

2026년 9월 21일 · 저장소·실험 기록·수상 사례·관련 문헌을 대조한 연구 기획

## 1\. 선정 결론

**추가 실기 실험을 할 수 있고 약 6\~7주가 있다면, 가장 추천하는 주제는 「측위 불확실성과 행동별 요구조건을 연결한 실내 이동로봇의 주행 판단」이다.** 부제는 **「방향 전환과 도착 판정에서 오판과 불필요한 정지의 절충 분석」**으로 잡는다. 계단은 중요한 검증 환경으로 사용하되, 장소 이름을 연구 기여로 삼지 않는다.

쉬운 설명은 다음과 같다. 로봇이 자기 위치를 조금 불확실하게 알아도 어떤 동작은 계속할 수 있다. 하지만 같은 정보로 회전이 끝났다고 판단하거나 목적지 도착을 선언하면 잘못될 수 있다. **현재 수행하는 동작에 실제로 필요한 정보만 골라, 그 정보의 오차가 허용 범위 안에 있는지 판단하는 방법을 만들고 검증한다.** 센서가 잠시 나빠졌다는 이유로 모든 것을 중단하는 비용과, 불확실한데도 다음 동작으로 넘어가는 비용을 함께 측정한다.

이는 **INFERRED: 후보 간 상대적인 기획 판단**이다. 수상 확률을 산출한 결과나 세계 최초의 알고리즘 판정이 아니다. 현재 증거만으로 수상 경쟁력이 충분하다고 결론내릴 수 없다. 아래의 독립 평가와 기존 구현 대비 비교를 통과하면, 실제 문제·명확한 기여·재현 가능한 결과를 갖춘 학부 연구가 될 가능성이 가장 크다는 뜻이다.

**선정 조건은 엄격하다.** 현재 코드에도 관측 시각, 단계별 기하 조건, 정착 확인이 이미 있다. 새 연구는 이것을 다시 소개하는 데서 끝나면 안 된다. 올바르게 보정하고 충분히 조정한 기존 구현을 상대로, 새로운 주행 기록에서도 오판과 정지의 관계를 개선해야 한다. 그 이득이 없으면 이 주제를 고집하지 않는다.

추가 실험이 불가능하거나 남은 시간이 1\~2주라면, 아래 2순위인 **「관성 보조 LiDAR 측위에서 초기 자세·회전 예측·실패 판정의 영향 분리」**가 더 현실적이다. 이는 완성 가능성이 높은 실증 분석 주제지만, 현재의 내부 정합 수치만으로 위치 정확도 향상을 주장할 수는 없다.

## 2\. 어떤 기준으로 골랐는가

이 연구는 제품 기능 경연이 아니라 학부 연구 발표를 우선 가정한다. 대상 행사와 추가 실험 가능 범위는 사용자에게 질문했으며 아직 확인되지 않았다. 경희대 2026년 학부 연구생 학술제라면 공식 공고상 행사는 11월 10\~13일, 접수 마감은 **9월 21일 23:59**다. 따라서 오늘 신청해야 하는 경우 연구 초록의 완료 결과와 앞으로 할 실험을 분리해야 한다. 미래 성과를 완료형으로 쓰면 안 된다. [경희대 공고](https://com.khu.ac.kr/biz_kor/user/bbs/BMSR00040/view.do?boardId=549586&menuNo=14500163)

기존 [수상 사례 조사](../undergraduate-research-awards-20260921/report.md)는 중복을 제외한 37건을 정리했다. 교내 학부 연구 프로그램 계열 16건과 외부 학회 학부생·대학생 논문상 21건이며, 동일 종류의 대회 37개가 아니다. 미수상작과 심사 점수는 확보하지 못했다. 따라서 수상작에서 보이는 특징은 참고할 수 있지만 수상 원인이나 확률로 해석할 수 없다.

### 5.1 관성 보조 LiDAR 추적

| 105713 | 167/339 → 339/339 | 33.61 → 11.02cm | 동일                       |

**OBSERVED:** 보존된 비교 결과의 수치다. 이번 조사에서 BAG를 다시 계산한 값은 아니다. 정합 잔차는 실제 로봇 위치 오차가 아니다. 102101의 잔차 중앙값은 7.85→7.90cm로 소폭 커졌다. 정합이 모두 수락되었다고 100% 정확한 것은 아니다.

변경은 중력으로 초기 위쪽 방향 설정, 고정 센서 회전 보정, 자이로 기반 정합 초기 회전, 실패 출력 처리다. GICP 목적함수 자체를 새로 만든 것은 아니다. 수락 임계값 숫자는 유지했지만 비교 기준 자세가 직전 수락 자세에서 자이로 예측 자세로 바뀌었다. 따라서 거절 감소의 원인을 회전 예측 하나에 귀속시키면 안 된다. ## 6\. 추천 주제를 실제 연구로 만드는 방법

### 연구 질문과 가설

**연구 질문:** 같은 측위기와 같은 기본 제어기를 사용할 때, 행동에 필요한 관측 성분과 허용 오차를 따로 판단하면, 기존 고정 기준보다 잘못된 단계 전환을 늘리지 않으면서 불필요한 정지와 도착 지연을 줄일 수 있는가?

**검증 전 가설:** 직진에 필요한 횡방향 위치·방향 정보와, 회전/도착 완료에 필요한 누적 진행·종료 방향·경계 통과 정보는 다르다. 이를 하나의 신뢰 점수나 고정된 시간 만료 기준으로 다루는 것보다, 행동별로 필요한 성분을 검증하는 편이 유리한 조건이 있을 것이다. ‘어떤 조건에서 유리한가’도 결과에 포함한다.

다만 직진도 진행 방향 경계에 가까우면 종방향 정보가 필요하다. ‘횡방향이 맞으면 항상 직진 가능’ 같은 단순 규칙은 사용하지 않는다. 동작 허용 여부와 단계 완료 여부를 나누되, 현재 동작의 기하적 여유와 실제 제어 가능성을 함께 확인한다.

### 구체적으로 무엇을 새로 만드는가

**1. 현재 기록을 물리적 오차와 연결한다.** 정합 잔차·관측 나이·회전 변화·연속 실패가 실제 위치/방향 오차를 얼마나 예측하는지 별도 기준으로 측정한다. 잔차가 낮지만 틀린 정합도 포함한다. 현재 GICP 점수를 곧바로 ‘95% 신뢰도’로 바꾸지 않는다. 소량 데이터에 복잡한 학습 모델을 추가하지 않고, 우선 단순한 오차 구간의 유효성을 확인한다.

**2. 판단 대상마다 요구 성분을 정의한다.** 직선 구간의 제한된 주행 유지, 방향 전환 완료, 목표 구역 도착을 구분한다. 평지에서도 모두 시험할 수 있다. 계단에서는 회전 가능한 계단참 진입과 상부 구역 도착으로 확장하되 기하적 위치 확인과 실제 접지·균형 보장을 구분한다.

**3. 고정 마진과 고정 나이를 행동별 오차 여유와 비교한다.** 예를 들어 위치 추정에서 구역 경계까지 남은 여유가 작으면 같은 10cm 오차도 중요해지고, 충분히 넓은 구간에서는 허용 가능할 수 있다. 설명용 표현은 다음과 같다.

`판단 여유 = 해당 행동의 허용 범위 − 보정 자료에서 확인한 추정 오차 범위 − 관측 이후 이동의 불확실성`

실제 구현에서는 위치·각도를 같은 단위로 더하지 않는다. 각 성분별로 판단하거나 방향 오차가 로봇 외곽의 위치 오차에 미치는 영향을 기하적으로 계산한다. 오래된 관측을 사용할 때는 실제 속도와 그 오차·시간 동기 오차를 반영한다. ‘명령 속도 × 지연’만으로 실제 이동을 보증하지 않는다.

이것은 **제안하는 설계이며 아직 성능이 검증된 알고리즘이 아니다.** 경험적 오차 구간을 사용하므로 형식적 충돌 회피나 전도 방지 보장도 아니다. 실측 구간 밖에서 오차가 커지는 경우를 실패로 기록한다.

**기존 고정 기준과 다른 결정을 내리는 예시.** 다음은 성능 결과가 아니라 알고리즘 차이를 설명하는 가상 사례다. 다른 도착 조건은 같다고 두고, 기체 후단이 목표 구역 경계를 얼마나 지났는지 판단한다. 행동별 고정 기준 B2는 언제나 15cm 오차 여유를 적용한다. 제안 P는 보정 자료에서 관측 나이와 정합 상태별로 확인한 오차 범위를 매 관측에 적용한다.

| 같은 입력에 대한 비교                                 | B2: 고정 15cm               | P: 관측 상태별 오차 범위            |
| -------------------------------------------- | ------------------------- | -------------------------- |
| 추정상 경계 통과량 8cm, 새롭고 양호한 관측, 보정 오차 범위 3cm     | 8−15 \< 0, 아직 완료하지 않음     | 8−3 \> 0, 다른 공통 조건도 맞으면 완료 |
| 추정상 경계 통과량 16cm, 오래되거나 불량한 관측, 보정 오차 범위 18cm | 16−15 \> 0, 다른 조건이 맞으면 완료 | 16−18 \< 0, 새 관측을 기다림      |

P의 오차 범위는 행동별 상수를 다시 이름 붙인 값이 아니다. 보정 자료에서 **각 관측 상태의 추정값과 같은 판단 시각의 외부 정답 사이 오차**를 모아, 사전에 정한 분위수로 정하는 단순 구간표부터 시험한다. 관측 나이·정합 상태 구분은 적게 유지하고 최종 시험 전에 고정한다. 이 방식은 판단 시각까지의 지연 효과가 오차에 포함되므로 지연 마진을 다시 더해 중복 계산하지 않는다. 표본이 부족하거나 보정 자료 밖인 상태에서는 작은 오차 범위를 임의로 부여하지 않고 공통 보수 기준으로 돌아가거나 판단을 유보한다. 어떤 구간도 실제 오류를 잘 구분하지 못하면 P는 성립하지 않는다. 위 3·15·18cm는 설명용 숫자이며 현재 로봇에서 측정하거나 배포한 설정이 아니다.

**4. 판단과 복구를 기록한다.** 다음 단계로 넘어가지 못한 이유를 ‘어떤 관측 성분이 얼마만큼 부족했는지’로 남기고 새 관측으로 다시 평가한다. 계속 움직이려면 해당 동작 자체의 요구조건이 충족되어야 한다. 계단에서 정보가 부족할 때 0 명령이면 안전하게 대기한다고 가정하지 않는다. 별도로 검증된 물리적 대응이 없다면 자동 복구 성공으로 집계하지 않는다.

### 기존 구조와의 관계

새 SLAM, 새 ROS 노드, 새 mission manager를 만들 필요가 없는 연구 설계다. 주된 비교 지점은 기존 Stair Supervisor의 관측 평가 함수와 진단 자료다. 추적 코어·기본 제어·경로·기체 형상은 비교군 사이에서 고정한다. 계산 결과의 측정 시각과 epoch 보존도 모든 정상 비교군에 공통 적용한다.

기준점이나 좌표 변환이 잘못된 경우는 먼저 모두 수정한다. 그것을 일부러 잘못 둔 비교군만 이겨서는 연구 기여가 성립하지 않는다. 현재 단계에서는 계획만 제시했으며 운영 코드와 설정을 변경하지 않았다.

## 7\. 비교 실험과 평가 기준

### 비교군

| 군                       | 역할                       | 통제 조건                     |
| ----------------------- | ------------------------ | ------------------------- |
| B0: 올바르게 보정한 현재 구현      | 가장 중요한 실용 기준             | 현재 단계별 조건·히스테리시스·시각 보존 포함 |
| B1: 전역 고정 기준            | 같은 기준을 모든 행동에 적용하는 경우    | 합리적인 여러 임계값을 탐색           |
| B2: 행동별 고정 기준           | 제안 기법이 단순 조건 분리보다 나은지 검사 | B0가 이를 포함하면 B0와 합쳐 중복 제거  |
| P: 행동별 요구조건 + 보정한 오차 범위 | 제안 방법                    | 동일 측위·기본 제어·경로 사용         |
| P의 구성요소 제거              | 효과의 원인 분석                | 시간만, 기하만, 둘을 결합한 경우를 분리   |

각 군의 튜닝 자료와 시간 예산을 맞춘다. 제안 방법만 오랫동안 조정하고 기본값 비교군과 비교하지 않는다. 잘못된 시각을 새 관측처럼 붙이거나 틀린 외부 파라미터를 넣는 시험은 오류 설명용으로 별도 분리한다.

### 실험 단위와 독립 정답

기존 BAG는 재현·설계용으로 쓰고, 새 시험은 날짜나 독립 주행 단위로 보정용과 최종 시험용을 나눈다. 같은 주행의 인접 프레임을 나눠 학습·시험으로 쓰지 않는다. 최종 시험을 본 뒤 수정하면 새 시험 기록을 다시 확보한다.

정답은 추정기에 넣지 않는 외부 카메라·로봇 상부 마커·측량한 구역 경계 등으로 만든다. TaskSLAM-Bench의 외부 카메라 방법은 도착 반복성 평가에 참고할 수 있다. 다만 그 논문의 도착 평가 방식을 계단의 순간 단계 전환에 그대로 쓰지 않고, **이 연구의 시간 오차와 위치 오차를 별도로 측정**해야 한다. 기준 장치 오차가 확인하려는 개선보다 크면 실험을 바꾸거나 차이를 결론내리지 않는다. [TaskSLAM-Bench 측정 설계](https://arxiv.org/html/2409.16573v3#S2.SS2.SSS3)

외부 카메라가 보지 못한 프레임은 정답 불명으로 처리한다. 로봇 전체가 상부 구역에 들어갔다는 기하적 판정과 실제 하중 지지가 안정적이라는 판정을 혼동하지 않는다. 후자는 별도 물리 측정 없이 이 연구의 성과로 포함하지 않는다.

### 단계적으로 진행할 시험

| 단계              | 시험 내용                      | 얻을 수 있는 결론              |
| --------------- | -------------------------- | ----------------------- |
| 기존 자료 재생        | 정합 구성요소 분리, 관측 시각·중복·중단 교란 | 추정 출력과 판단 로직의 반응, 원인 후보 |
| 외부 기준이 있는 평지 시험 | 직선·180° 방향 전환·지정 구역 도착     | 실제 판단 오차, 지연, 복구, 반복성   |
| 별도 날짜/출발 자세 시험  | 조정하지 않은 조건에서 동일 임무         | 해당 범위의 재현성과 일반화         |
| 계단 시험           | 계단참 진입·회전·상부 구역 도착         | 계단으로의 적용 범위와 물리적 한계     |

지연·데이터 누락 교란은 자연 기록의 분포를 먼저 확인하여 범위를 정한다. 모든 비교군에 같은 교란을 적용한다. 교란을 주입한 사실이 ‘로봇이 잘못된 행동을 했다’는 정답은 아니다. 실제 구역/방향과 비교해야 한다.

BAG 재생에서는 가상의 명령이 기록된 이동을 바꿀 수 없다. 따라서 **재생으로 완주율이나 제어 안정성을 입증하지 않는다.** 실제 명령에 따라 움직인 실험에서만 폐루프 성공률을 집계한다. 개입한 시행도 삭제하지 않고 개입 시각·이유를 결과에 포함한다.

### 핵심 지표

| 지표           | 정의와 주의                                                                                                    |
| ------------ | --------------------------------------------------------------------------------------------------------- |
| 잘못된 단계 전환    | 독립 기준상 조건을 만족하기 전에 다음 단계로 넘어간 사건 / 평가 가능한 전환 기회                                                           |
| 미전환·과도한 지연   | 조건을 만족했는데 제한 시간 안에 전환하지 않은 사건과 지연 시간                                                                      |
| 주행 제한과 전환 지연 | 정지·제한 시간 자체는 그대로 기록. 불필요 여부를 판정할 수 있는 경우에 한해, 공통 외부 완료 조건 충족 이후의 대기 시간을 집계. 동적 안전이나 반사실적 주행 가능성으로 확대하지 않음 |
| 물리적 임무 완료    | 사전 정의한 구간을 허용 개입 규칙에 따라 완료한 시행 / 시작한 전체 시행                                                                |
| 사람 개입과 복구    | 개입 횟수, 새 관측 이후 복구 시간, 재시작·재위치지정 필요 여부                                                                     |
| 위치·방향·나이 오차  | 기준 장치 오차를 함께 기재한 실측 오차, 실제 관측 나이와 판단 시점                                                                   |

평가에 쓰는 완료 조건은 방법 설계 전에 정한다. 예를 들어 외부 기준상 기체 후단이 측량 경계를 넘고 실제 방향이 목표 범위에 들어갔는지를 사용한다. 이 기준은 B0·B1·B2·P 모두 같다. **P의 신뢰도나 관측 허용 규칙을 정답 판정에 사용하지 않는다.** 외부 계측 오차 때문에 경계 통과가 애매한 구간은 판정 불명으로 남긴다. 도착 뒤 지연은 이 방식으로 비교할 수 있지만, 주행 도중의 모든 정지가 불필요했는지는 알 수 없다. 그 구간은 정지 시간으로만 보고하고, 실기 임무 시간·완료율로 실용적 비용을 함께 평가한다.

주요 그림은 **오판율과 불필요한 제한/완료 지연의 관계**다. 두 지표를 자의적 점수 하나로 합치지 않는다. 같은 오판 수준에서 더 적게 제한하거나 같은 제한 수준에서 더 적게 오판하는 영역이 있는지 비교한다. 모든 비교군에서 오판이 0이어도 지연 차이는 평가할 수 있다. 다만 관측된 오판 0만으로 실제 위험이 같거나 증가하지 않았다고 입증할 수는 없으며, 표본 수에 따른 불확실성을 함께 보고한다.

처음에는 조건별 소수의 독립 시행으로 분산과 소요 시간을 조사한다. 이것을 최종 표본 수나 충분한 통계 검정으로 제시하지 않는다. 최종 반복 수는 검출하려는 효과와 예비 분산을 보고 정하고, 주행 단위 신뢰구간을 제시한다. 수천 개 프레임을 수천 개 독립 실험으로 세지 않는다.

### 평가에 숨어들기 쉬운 순환 논리

`mandela` 점검에서 이 계획에 직접 적용되는 위험은 다음 세 가지다.

  - **Shared hallucination / Tautology:** 추정에 사용한 계단 형상이나 자이로와 잘 맞는다는 이유로 정답이라고 판단할 위험. 외부 기준으로 수정한다.
  - **Verifier = designer:** 동일 BAG를 보며 방법과 평가 조건을 함께 조정할 위험. 기준·비교군을 고정하고 독립 주행으로 시험한다.
  - **Wrong null hypothesis:** ‘자이로만 제거’했다고 하면서 수락 기준 자세·초기화까지 함께 달라질 위험. 입력과 판정 기준 변화를 각각 통제한다.

## 8\. 가장 먼저 할 일과 중단 기준

**첫 일주일은 본 구현 확대가 아니라 주제의 성립 여부를 확인하는 기간이다.** 우선 외부 카메라와 마커·측량 도구를 확보하고, 기체 전체와 경계가 함께 보이는 평지 시험장을 사용할 수 있어야 한다. 실제 확보 여부는 아직 UNVERIFIED다. 첫 이틀에 정지 기준점과 알려진 이동으로 외부 위치·방향 오차를 측정하고, 동시 기록 가능한 시각 사건으로 카메라와 판단 로그의 시간 오차를 확인한다. 예를 들어 5cm 또는 100ms 정도의 차이를 논하려면, 외부 기준 오차를 각각 1cm·20ms 이하로 만드는 것을 설계 목표로 둘 수 있다. 이는 장비 성능 보증이나 보편적인 통계 기준이 아니다. 충족되지 않으면 더 큰 효과만 평가하거나 장치를 바꾼다.

첫 주 자료는 적어도 서로 다른 출발 자세·관측 상태를 포함한 독립 주행과, 보정에 쓰지 않은 재시험을 확보할 수 있어야 한다. 예비 시행의 작은 수로 최종 우월성을 선언하지 않는다. 장비 구성에 일주일을 다 쓰거나 재시험을 확보하지 못하면 주제 확정을 연기하거나 2순위로 전환한다.

1.  현행 경로 기준점·센서 변환·기체 형상·관측 시각을 정리하고, 모든 비교군에서 동일하게 적용한다. 기존 기록의 SUPPORT\_LIMIT/CORRIDOR\_LIMIT가 설정 문제인지 구분한다.
2.  외부 기준으로 평지의 방향 전환/도착을 측정하는 작은 시험을 구성한다. 사용자 운용자가 원하면 현재 주행과 별도로 관찰만 하는 방식으로 먼저 판단 출력을 수집한다.
3.  정상 관측과 지연·부분 누락 조건에서 현행 기준을 합리적인 범위로 조정하여 기준 성능 곡선을 얻는다.
4.  작은 제안 구현이 그 곡선보다 실제로 나은 영역을 만드는지 확인한다. 기준 장치 불확실성보다 작은 차이는 이득으로 세지 않는다.

| 예비 결과                            | 결정                                     |
| -------------------------------- | -------------------------------------- |
| 같은 오판 수준에서 제한·지연이 줄고 독립 반복에서도 유지 | 1순위 주제로 진행                             |
| 기존 고정 기준을 제대로 조정하면 차이가 사라짐       | 새 판단 기법의 우월성 주장을 중단. 단순 구현 사용          |
| 기준점 수정만으로 문제가 사라짐                | 설정·좌표계 원인 분석으로 연구 질문을 축소               |
| 내부 품질 지표가 실제 오차를 예측하지 못함         | 확률·신뢰도 주장 중단. 별도 관측 추가 비용과 주제 전환 검토    |
| 외부 기준 또는 실기 접근 불가                | 2순위 구성요소 분석으로 전환. 물리 정확도·폐루프 주행 주장은 제외 |

이 중단 기준은 연구를 포기하기 위한 것이 아니다. ‘이미 만든 코드가 있으니 반드시 새 알고리즘이라고 발표해야 한다’는 결론을 피하고, 실제로 확인되는 기여를 선택하기 위한 것이다.

## 9\. 약 7주가 있을 때의 작업 순서

| 기간    | 산출물                                                |
| ----- | -------------------------------------------------- |
| 1주    | 선행연구 표, 현행 코드/설정 동결, 독립 기준의 오차 측정, 예비 비교와 계속/전환 결정 |
| 2주    | 비교군 구현과 관측·판정 로그, 평지 조건의 보정 자료                     |
| 3주    | 최종 기준 고정, 별도 평지 주행, 구성요소 제거 비교                     |
| 4\~5주 | 가능한 범위의 계단·다른 시작 자세/날짜 검증, 실패 사례 정리                |
| 6주    | 주행 단위 통계, 기존 방법과의 차이·비용·적용 한계 정리                   |
| 7주    | 발표 자료, 짧은 비교 영상, 예상 질의응답, 결과 재현 확인                 |

필수 결과는 평지의 독립 검증과 충분한 기존 구현 비교다. 계단까지 완료하면 응용 가치와 실증 범위가 커진다. 계단을 못 했는데 발표 제목과 결론을 자율 계단 주행 성공으로 유지하지 않는다. 실험 접근이 제한되면 일정과 제목을 조정한다.

UI, 이메일, 자동문, 층간 미션 전체 확대는 이 연구의 비교 변수가 아니다. 기존 자산을 설명하는 마지막 시연에 넣을 수 있으나 논문의 중심 실험을 지연시키면 제외한다.

## 10\. 발표를 강하게 만드는 구성

발표 첫 장은 기능 목록 대신 **측위 결과가 그럴듯해도 행동 판단은 틀릴 수 있고, 반대로 보수적인 판단 때문에 주행이 불필요하게 중단될 수 있다는 실제 비교**로 시작한다. 아직 이런 실측 비교를 확보하지 못했으면 가설 그림이라고 표시한다.

발표의 중심은 네 가지다.

1.  실제 기록에서 확인한 실패와 그중 설정 문제로 분리한 부분.
2.  기존 방법에 이미 있는 기능과 이번 연구에서 추가한 규칙.
3.  동일 조건에서 비교한 오판·제한·지연의 관계와 독립 시험 결과.
4.  성공 장면과 함께 남은 실패 조건, 외부 기준의 오차, 사람이 개입한 시행.

경희대 구두 발표 형식이라면 12분 안에 질문 1분, 관련 연구/현재 한계 2분, 방법 3분, 결과 4분, 한계/기여 2분 정도로 구성할 수 있다. 이는 추천 구성이지 심사 규정의 배점이 아니다.

가장 중요한 예상 질문은 ‘그래서 원래 상태머신 조건문과 무엇이 다른가?’다. 답은 **“행동별 조건문을 처음 만든 것이 아니라, 실제 오차와 행동의 허용 범위를 연결하고, 충분히 조정한 현행 조건보다 어떤 상황에서 얼마만큼 나아지는지 독립 실험으로 보였다”**여야 한다. 아직 그 결과가 없으면 그 질문에 완전히 답할 수 없는 상태다.

다음 표현은 결과 없이 사용하지 않는다: 세계 최초, 모든 계단, 완전 자율, 안전 보장, FAST-LIO보다 정확, 100% 정확, 연구자가 직접 개발한 SLAM. 기존 알고리즘·참고 코드·AI 보조·사람이 설계하거나 수행한 부분의 역할을 정확히 구분하고 실제 행사 규정을 확인한다.

## 11\. 이 보고서의 완료 범위

**OBSERVED:** 로컬의 관련 코드·분석 결과와 공개 선행연구·대학 자료를 대조하여 후보 선정 및 검증 계획을 작성했다. **INFERRED:** 1순위가 현재 자산과 사용자 목표를 가장 잘 연결한다는 판단. **UNVERIFIED:** 실제 개선 폭, 미관측 환경 일반화, 수상 가능성, 전체 자동 계단 주행과 물리적 균형 유지.

이번에는 저장소 전체 감사를 새로 수행하거나 실험을 실행하지 않았다. 원본 BAG·운용 코드·기존 worktree 수정 사항은 변경하지 않았다. 이 디렉터리의 보고서와 생성·검증 기록만 추가했다. 최종 검증 기록에서 문서 링크와 기록 전후 Git 상태를 확인한다.

**최종 추천:** 발표 주제의 범위는 ‘실내 로봇의 신뢰할 수 있는 행동 판단’으로 잡고, 실제 연구 기여는 ‘행동별 요구조건과 오차 범위의 연결이 기존 고정 기준보다 유리한가’라는 하나의 검증 가능한 질문으로 제한한다. 이를 먼저 작은 실험으로 입증한 뒤 계단에 확장하는 것이, 현재 상황에서 의미와 완성 가능성을 함께 확보하는 가장 설득력 있는 경로다.

2026-09-21 · 연구 기획 보고서 · 제안 성능은 실험 전 가설이며 수상 확률이나 물리적 안전 보장을 뜻하지 않습니다.
