# 문서 보관·적용 준비 작업 기록

요청 해석: 지금까지 생성한 HTML 보고서를 Markdown으로 보관하고, 계단 주행 개선 완료 시의 결과와 실제 적용 절차를 명확히 기록한다. 구현까지 이번에 진행할지는 비동기로 범위를 확인 중이며, 답변과 무관한 문서 보관부터 진행한다.

범위: 현재 프로젝트의 생성 HTML 18개. sources/ 동기화 참조 및 .git 제외. 원본 보고서와 원본 BAG를 수정하지 않는다.

진행 결과:

- HTML 18개를 Markdown으로 옮기고 미디어 42개(MP4 3개 포함)를 복사했다. 원본과 변환 목록·해시를 manifest에 기록했다.
- 본문 블록 4,804개를 대조했고 누락은 없었다. 변환 중 맞춤 anchor와 SVG 설명 누락을 발견해 고친 뒤 전체를 다시 변환했다.
- 현재 결과·남은 문제·개선 후 목표·기존 검사 명령·실제 설정 조회·후속 코드와 검증 도구 위치를 적용 안내에 정리했다.
- 별도 검토자의 세 지적을 반영한 후 안내 본문 재검토를 받았다.
- 로컬 소프트웨어 검사를 실행해 통과했다. 검사 전후 Git 상태가 같고 임시 ROS 캐시는 제거됐다. 원격 장비 접속은 하지 않았다.
- 운영 코드·설정 변경이나 실기 주행은 수행하지 않았다. 전체 계단 복구 구현 범위에 대한 비동기 질문에는 아직 답변이 없으며, 문서 작업 완료를 구현 완료로 보고하지 않는다.

최종 산출물과 검사 범위는 README.md·VALIDATION.md에 기록한다. 새 구현 또는 실기 결과가 생기면 APPLICATION_GUIDE.md를 갱신하고 과거 보고서 보관본은 유지한다.
