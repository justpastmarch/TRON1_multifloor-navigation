# 문서 보관 검증 기록

2026-09-22. 검증 대상은 이번 문서 보관본과 최신 적용 안내다. 과거 18개 보고서의 실험을 전부 재실행하거나 전체 저장소 감사를 다시 완료했다는 의미가 아니다.

## 내용과 파일 보존

- 프로젝트 내 생성 HTML 18개를 모두 Markdown으로 변환했다. 동기화 참조 `sources/`와 `.git`은 범위에서 제외했다.
- 본문·목록·표 셀·제목 4,804개 텍스트 블록을 변환 결과와 대조했고 누락은 0개였다. 변환 도구의 정규화 비교이므로 원본 HTML과 동일한 화면 배치를 보증하는 검사는 아니다.
- 이미지·SVG·영상 42개를 보관했다. 영상은 MP4 3개이며 변환·재인코딩 없이 원본 바이트를 복사했다.
- HTML의 검색·접기·재생 시점 이동은 정적 본문과 링크·시각 설명으로 옮겼다. SVG 도표는 그림과 문자 내용을 함께 보존했다.
- 원본 HTML과 복사한 미디어의 SHA-256, 보관 문서의 SHA-256을 확인했다. 상세 목록은 [manifest.json](manifest.json), 최종 링크·해시 검사는 [conversion-validation.json](conversion-validation.json)에 있다.
- 문서·포함된 미디어 사이의 상대 링크는 폴더 전체를 옮겨 사용할 수 있다. 원본 코드·BAG·보조 분석 자료를 가리키는 절대 링크는 기존 컴퓨터의 해당 파일이 필요하다.

## 적용 안내 확인

- 기존 실행 스크립트, launch, Supervisor와 LiDAR adapter 코드를 읽고 확인 명령·설정 우선순위·토픽 이름을 대조했다.
- `rosparam get`과 `rostopic echo -n 1`의 조회 동작은 설치된 ROS Noetic의 `rosparam/__init__.py`, `rostopic/__init__.py`에서 확인했다. 저장소가 정한 실행 경로와 ROS 도구 동작을 구별했다.
- 새로 실행한 검사는 로컬 `run.sh --check`뿐이다. **OBSERVED:** 2026-09-22 21:16 KST 종료 코드 0, 전체 로컬 검사 OK. 명령·시각·출력은 [local-check-result.json](local-check-result.json)에 있다. 첫 시도의 시스템 버스 권한 오류를 실제 PC의 시간 동기 실패로 해석하지 않았다.
- `--preflight`, 실행 중 ROS 설정 조회, 센서 실행, 로봇 명령은 이번에 수행하지 않았다. 현재 장비 상태·실기 주행 결과는 **UNVERIFIED**다.
- 독립 검토자는 색인과 적용 안내의 핵심 본문을 읽었다. 통과 기준, 실제 설정 확인법, 후속 개발 자료 위치가 빠졌다는 세 지적을 반영했다. 수정 본문 재검토 결과는 ‘현재 상태·확인 절차 안내로서 독립적으로 이해 가능’이다. 전체 보고서의 사실 정확도나 실제 장비 실행에 대한 검증 판정은 아니다.

## 변경·임시 자료 관리

- 운영 저장소의 코드·설정과 원본 HTML·영상·BAG를 수정하지 않았다.
- 로컬 검사 직전·직후 `git status --porcelain=v1 -uall` 결과는 같았다. 이는 해당 검사 구간에 대한 확인이며 과거 다른 작업까지 포함한 Git 상태 불변 주장이 아니다.
- 로컬 검사에서 생성한 임시 ROS 캐시는 별도 임시 폴더에 격리하고 검사 종료 후 제거했다. 생성·제거 경로는 검사 결과 JSON에 남겼다. 첫 제한 환경의 캐시 쓰기 시도는 거부되어 파일을 만들지 못했다.
- 로봇·미니PC에 접속하거나 지속 실행 프로세스를 생성하지 않았다. 보관 폴더의 문서·변환/검증 도구·검사 JSON과 ZIP은 요청한 최종 산출물이다.

## 실제 주행 준비 상태

문서 보관은 완료됐다. 계단 주행 복구의 전체 구현·실기 적용은 별도 미완료 상태다. 시작 명령 수정 반영, 공통 계단 경계 정합, 단계 전환 검증, 연결 시험 구현과 실기 확인이 남았다. 과거 BAG 추적 개선이나 로컬 검사 통과를 자동 계단 완주 증거로 사용하지 않는다. [최신 적용 안내](APPLICATION_GUIDE.md)에서 예상 결과와 남은 순서를 확인한다.
