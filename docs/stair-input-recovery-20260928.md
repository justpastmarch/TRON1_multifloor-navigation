# 계단 주행 입력 지연 복구 — 2026-09-28

현재 로컬 정책 버전은 `2026-09-28-input-recovery-v9`이다. 실행 중인 Supervisor는 재시작하지 않았다. 이 작업에서는 주행 명령을 보내지 않았다. 새 ROS 노드·상위 상태는 추가하지 않았으며 기존 SensorJoy 수신기를 재연결했다.

## 변경

기존에는 유효 관측 나이가 0.9초에 도달하면 시험 전체가 종료됐다. 선택적 `flight_input_recover_sec`를 설정한 상승 구간에서는, 이미 전진하던 중 같은 측위 epoch의 관측이 잠깐 늦어지면 0 명령을 보내며 기다린다. 설정값은 기존 `recover_sec` 상한과 같은 누적 2초/상승 구간이다. 0.9초 만료 판정 자체는 그대로이며 오래된 관측으로 전진하는 유예가 아니다.

재개에는 더 최신 sequence의 유효 관측과 `warn_sec=0.5` 이내 신선도가 필요하다. 이후 자세·지지영역·경로 검사를 다시 수행하고, 기존 `flight_restart_v=0.55` 명령 자체의 경로가 허용될 때만 그 입력으로 재개한다. 각속도 제한은 유지한다. 재개 경로가 부적합하면 기존 경로 재관측 처리로 넘어가며 낮은 입력의 경로를 검사해 놓고 높은 입력을 송신하지 않는다.

epoch 변경, 작업자 오류, 음수/유효하지 않은 시간, interrupt, 예산 초과는 자동 재개 대상이 아니다. 진입 정렬과 두 번째 상승 전 정렬, 계단참 높이 불일치 상황도 이 기능으로 덮어쓰지 않는다. phase/임무가 새로 시작되면 복구 누적값을 초기화한다. 0 명령은 물리적 정지·자세 유지가 아니며 RC 개입 조건은 유지한다.

`sensor_joy_session.sh`는 기존 수신기의 실제 메시지 발행을 검사한다. ROS 마스터 재시작 후 프로세스만 남고 토픽이 없으면 해당 설치 경로의 수신기를 정상 종료하고 재시작한다. 종료를 기다려 중복 실행을 피하며, 메시지를 수신해야 성공으로 반환한다. `run.sh`의 정상 시작 경로에서도 이를 호출한다. 수신 실패는 명확한 경고로 표시하고 전체 주행 스택을 강제로 종료하지 않는다.
