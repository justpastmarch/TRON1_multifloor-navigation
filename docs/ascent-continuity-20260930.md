# 상승 연속성 및 실패 후 녹화 개선

2026-09-30. 소스·설정 수정과 오프라인 검증을 마치고 실행 중 스택에도 v13을 적용했다. 사용자가 5층 첫 계단 아래 평지에 있음을 확인한 뒤 정상 재시작했다. 주행 목표는 보내지 않았으며 기존 스택의 연결 및 0속도 heartbeat가 실행 중이다.

## 사용자 동작

테스트 주행이 실패하면 BAG 녹화를 계속한다. 수동 복구와 이후 재시도도 기록할 수 있다. UI는 `복구 녹화 중 · 정지를 누르면 저장`을 표시한다. 테스트 버튼으로 재시도하면 기존 BAG을 이어 쓴다. 주행만 버튼은 녹화 종료 전 비활성화하여 기록 여부를 혼동하지 않게 한다. 정지 버튼은 녹화를 저장한다. 성공한 미션과 UI 정상 종료의 자동 저장은 유지한다. 용량 제한이나 파일 분할은 추가하지 않았다.

이전 미션의 늦은 완료 콜백이 새 세션을 종료하지 않게 기존 generation 검사를 유지한다. 저장 중에는 재시도를 막고, 기존 녹화가 재시험 준비 중 종료되면 주행 목표를 보내지 않는다. 재시도 전송 실패로 이미 진행 중인 복구 녹화를 버리지 않는다. 계단 소유권 복구 여부 등 기존 실제 주행 준비 조건은 별도이며, 녹화 재사용만으로 로봇이 자동 재개되지는 않는다.

## 제어 변경

정책 식별자 `2026-09-30-continuity-v13`.

- 외측으로 향하는 횡속도에 0.3초 선행 보정을 추가한다. 측정 위치와 속도의 횡방향 부호가 같고 관측이 정상일 때만 적용한다. 추가 횡오차는 기존 10cm 위치 밴드 이내, 중심선 포착각은 기존 10도 이내로 제한한다. 전체 각속도와 각가속도 상한은 그대로다.
- 3F→4F와 5F→RF 경로에 기존의 제한된 회복 조향을 활성화했다. 내부 각속도 명령 상한 0.06이며 정상 상한 0.2보다 작다. 실제 로봇의 회전 속도나 제자리 위치 유지가 검증됐다는 의미는 아니다.
- 회복 시 위치 불확실성 예산 10cm를 보존하면서 추가 2cm 여유를 회복하는 경로를 재관측에서도 허용한다. 큰 조향, 지지 경계 이탈, 오래된 센서, 예산 소진은 계속 거부한다. 회복 예산은 누적 2초이며 매 반복마다 초기화하지 않는다.
- 회복 조향의 목표값을 직전 제한된 출력과 분리했다. 실제 이전 출력과 시간 간격으로 가속도 제한을 적용하면서, 매 제어 주기 새 경로 검사를 통과한 작은 보정을 연속 출력한다. 송신하지 않은 가상 명령으로 변화율 제한을 우회하지 않는다. 최신 관측·gyro 두 방향의 지지와 회복 조건을 계속 검사한다.
- 현재 몸체는 10cm 여유 안에 있지만 고정 간격 보간 오차 때문에 경로가 탈락하는 경우, 경로 샘플 수를 17→65개로 높인다. 그에 맞춰 보수적 보간 오차를 줄이며 실제 여유 기준은 낮추지 않는다. 최대 검사량은 고정 상한이 있다.

상승 전진 입력과 계단참 속도, 상태머신 구조, 노드 구성은 변경하지 않았다. 새 추적/제어 노드를 추가하지 않았다.
