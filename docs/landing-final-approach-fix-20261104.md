# 계단참 마지막 접근 교착 수정

2026-11-04. 수정 기준 commit: `fbd7e852bc7902398bb53e60ca854e507b028176`.

## 문제와 수정

**OBSERVED · Safety S2 / Mobility M4:** 현재 제어 코드의 5F→RF 가상 주행은 계단참에서 다음 상승 진입 조건을 만족하지 못하면서 전진·회전 출력이 모두 0으로 수렴했다. 위치 `(2.35608,1.14913,1.70)m`, 방향 168.73도에서 접근 목표까지 약 32.72cm가 남았다. 전후 투영 오차는 0에 가깝고, 방향 보정과 횡오차 보정은 서로 상쇄됐다. 정합은 TRACKED이고 연결 지지영역 여유는 약 12.15cm였다. 다음 상승 폭 판정만 약 0.498mm 부족하여 완료되지 않았다.

`stair_feedback.py`의 기존 목표 방향 접근 제어를 계단참의 마지막 이동 waypoint에도 적용했다. 목표가 옆에 있을 때 방향·횡오차 보정이 상쇄되어 멈추던 평형을 없앤다. 계단참→두 번째 상승과 옥상 회전→마지막 상승의 최종 접근을 같은 기존 분기로 처리한다. 회전 공간 확보를 위한 최소 이동 강제는 최종 상승 진입에 적용하지 않는다.

새 ROS 노드·FSM 상태·정지 gate를 추가하지 않았다. YAML, 상승 입력 0.55, 계단참 상한 0.195, 몸체 지지 여유, 회전 공간 여유, 높이·다음 상승 corridor 판정, 옥상 중앙 반경 35cm, 제한시간을 변경하지 않았다. 완료 판정을 강제로 참으로 만들지 않는다.

## 실패 전 / 통과 후 검증

`test_final_landing_approach.py`는 실제 교착 자세와 양쪽 횡방향 접근, 옥상 마지막 접근 등 5개 시작 조건을 검사한다. 제어 명령으로 가상 XY/yaw를 적분하고, 자연 완료 이후 다음 상승 입력 0.55까지 확인한다.

- 수정 전 3개 테스트 메서드 중 2개가 `supported final approach did not hand off`로 실패했다. 교착 자세와 아래쪽 횡편향에서 `TRACKED / current_supported=true / next_flight_corridor=false`가 지속됐다.
- 수정 후 3개 메서드·5개 시작 조건이 통과했다.
- 주변 10개 모듈의 등록 실행 169회와 독립 하강·옥상 검증 22회가 통과했다. import에 따른 중복을 포함하므로 독립 시나리오 수로 사용하지 않는다.
- 새 테스트를 CMake의 기존 수치 처리 의존 테스트 블록에 등록했다.
- bundle 검증 `BUNDLE_OK`, diff 공백 검사 통과.

실제 `StairSupervisor.traverse()`와 `StairFeedback`을 함께 구동한 연속 가상 주행:

| 초기조건 | 수정 전 | 수정 후 |
|---|---|---|
| 5F→RF, 중심·방향 정렬 | 계단참 교착, 가상 380초 timeout | 최종 모드 해제·성공 반환, 가상 81.8초 |
| 3F→4F, 중심·방향 정렬 | 통과 63.2초 | 통과 63.2초 |
| 5F→RF, 시작 위치 +15cm | 통과 63.6초 | 통과 82.4초 |
| 5F→RF, 시작 방향 +15도 | 통과 62.8초 | 통과 81.8초 |

수정 후 5F 중심 시작의 자연 전이 시각은 첫 상승 0.4초, 계단참 5.6초, 계단참 이동·회전 5.8초, 두 번째 상승 47.0초, 옥상 우회전 51.6초, 마지막 두 단 78.8초, 도착 확인 81.4초다. 모드 해제 이후 성공을 반환했다.

별도 0.1초 적분 제어기 루프에서도 정상 5F 시작과 상승 도중 횡방향 15cm·방향 15도 순간 변화가 모두 끝까지 통과했다. 이는 시작 조건 변경과 별개의 시험이다. 과거 계단참 초기 자세 2개 역시 다음 상승과 마지막 상승까지 진행했다. 이 두 시험은 첫 상승 이력이 없는 중간 시작이므로 전체 도착 성공 수에 포함하지 않는다.

## 남은 조건과 해석

**OBSERVED:** 첫 상승 중 방향을 순간적으로 30도 바꾸는 별도 가상 조건은 이후 몸체 지지영역 판정에서 여전히 `CORRIDOR_LIMIT`로 중단된다. 이 조건을 이번 수정으로 없앴다고 주장하지 않는다. 필수 hazard·최소 제약 여부를 이 시험만으로 증명하지 않았으므로 해당 gate를 KEEP으로 확정하지 않는다.

일부 기존 통과 조건은 접근 궤적 변화로 가상 완료시간이 늘었다. 과거 계단참 시작 자세의 인계도 약 5초 느려졌다. 이번 수정의 입증된 이점은 정지 평형 제거이며 최단 시간이나 최적 성능의 증명이 아니다. 속도 설정 자체는 바뀌지 않았다.

가상 운동은 이상적 차동구동이며 높이는 XY 좌표와 고정 경사면에서 계산한다. 현재 단계나 완료 판정으로 높이를 만들어주지 않는다. admission·모드 응답과 위치 센서는 가상 입력이다. 지형과 제어기가 같은 측량 설정을 공유하므로 통과 결과는 내부 일관성의 증거다. 실제 계단 충격·토크·미끄러짐·점군 정합·통신·UI 전체를 검증하지 않았다.

**OBSERVED**는 위 생산 메서드의 가상 실행·테스트 결과다. 실제 장비에서 같은 교착을 방지할 것이라는 효과는 **INFERRED**, 현장 연속 주행 성공은 **UNVERIFIED**다.
