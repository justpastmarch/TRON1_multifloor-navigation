# 지도 관리: 2D + 3D 지도, 진행률, 지도 이동, 사진 메일

2026-11-20 적용. 정지 조건·게이트 추가 없음. 지도 관리 프로그램은 로봇 이동 명령을 보내지 않는다.

## 변경

- **원본 LiDAR 녹화**: `연결·작성 시작` 때 기존 2D 기록과 함께 미니 PC에서 `/livox/lidar`, `/livox/imu`를 녹화한다(계단 주행과 같은 `remote_stair_record.sh`). `작성 종료` 때 마감한다. 원본은 미니 PC `~/.local/share/tron1-stair-supervisor/bags/map_<기록 ID>.bag`에 남는다. 녹화 시작에 실패해도 2D 작성은 그대로 진행하며 3D만 만들지 않는다(`raw.json`).
- **지도 만들기**: Gmapping 비교 대신 `2D(SLAM Toolbox 재생) → 3D` 순서다. 2D 재생에서 map→base_Link 경로(`trajectory.json`, 0.05 s 간격)를 저장하고, 미니 PC에서 원본 BAG을 그 경로대로 쌓아 3D 점군을 만든다(`remote_mapping_cloud.sh`, `mapping_cloud.py`). 미니 PC → 개발 PC로는 1 cm 정수 압축 파일 하나만 보낸 뒤 개발 PC에서 `cloud.ply`와 화면용 `cloud.bin`을 만든다. 3D 실패는 2D 결과를 지우지 않는다.
- **3D 자세 모델**: x, y, yaw는 2D SLAM 경로(점마다 보간해 회전 중 왜곡 보정), roll/pitch는 LiDAR IMU 보완 필터, 높이는 일정(평평한 바닥 가정). 장착값은 계단 설정의 `base_from_lidar`와 `lidar_imu_baseline.yaml`을 그대로 쓴다. 5 cm 격자, 격자당 2회 이상 관측만 남김, 0.5~25 m.
- **진행률**: 작업 상태에 단계·퍼센트·남은 시간을 표시한다. 2D 단계는 기록 길이만큼 실제 속도로 재생한다.
- **지도 이동**: 실시간 지도와 2D 결과는 끌어서 이동, 휠·두 손가락으로 확대, 더블클릭 맞춤. 3D는 끌어서 회전, 오른쪽/Shift 끌기 이동, 휠 확대, 높이 슬라이더(천장층을 감지하면 처음부터 그 아래만 표시).
- **사진 메일**: `현재 위치 촬영·메일 전송`. 주행 UI와 같은 수신 주소·발송 기록(`SCAN_OUTPUT_BASE/photos`)을 쓴다. 핫스팟 연결을 고려해 사진을 찍는 순간에만 카메라 영상을 구독한다.
- 기존 Gmapping 결과는 목록에서 그대로 보이고 내려받을 수 있다.
