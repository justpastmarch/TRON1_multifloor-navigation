# 계단참 속도 유지

두 상승 구간의 목표 입력만 1.0이다. 계단참 이동·회전과 도착 확인은 기존 hold_v=0.06, max_w=0.2를 유지한다. 선형 정규화 입력 상한은 0.06/0.55 ≈ 0.109이다.

OBSERVED: 기존 함수는 상승 명령 이력을 유지하여 감속 제한 때문에 평지 구간에서도 한동안 큰 명령을 낼 수 있었다. 수정은 기존 함수의 최종 선형 명령에 평지 구간 상한을 적용한다. 이 전환에서는 감속 변화율보다 구간 상한을 우선한다. 각도 제어·각도 변화율·지지영역 검사는 유지한다. 새 ROS 노드는 없다.

검증: tests.txt의 실제 제어 함수 회귀 테스트 94개 통과. 합성 위치의 명령 출력 검증이며 실제 주행이나 정확한 구간 전환 시점의 검증이 아니다. UNVERIFIED: 로봇의 실제 감속 거리·관성·등반 성공. 실제 로봇은 명령 0에서도 움직일 수 있다.

적용 상태: 일시적인 No route to host 이후 TRON 주소와 제어 포트, 센서 수신이 복구되었다. Supervisor에 남은 통신 오류를 해제하고 코드를 반영하기 위해 기존 실행 스택을 재시작했다(restart.json). 10:11:15 KST 관찰에서 NAV, connected=true, TRACKED, geometry_valid=true, 관측 나이 0.370초를 확인했다(ready.json). LiDAR·IMU·wheel odom·scan 모두 수신했다. 새 진입점 preview가 필요하다. 주행 목표는 보내지 않았다.

원본과 changes.patch, tests.txt, 재현용 run_tests.py는 증빙으로 보존했다. ROS 조회용 임시 로그는 삭제했다. 기존 사용자 변경은 보존했다.

독립 검토: 명령 단위와 실제 동역학의 구분을 확인했다. 회귀 테스트는 절댓값 상한을 확인한다. 실물 감속과 구간 인식의 타이밍은 검증하지 않았다. 설정값은 기존 YAML에서 가져오며 별도의 설정 복제는 추가하지 않았다.
