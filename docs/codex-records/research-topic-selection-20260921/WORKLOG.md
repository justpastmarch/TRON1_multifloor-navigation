# 연구 주제 선정 기록

요청: 현재 TRON 저장소와 실험 자산, 선행연구, 국내 학부 연구 수상 사례를 대조하여 가장 설득력 있는 학술제 주제를 선정한다. 이번 작업은 연구 기획이며 구현 변경이나 로봇 주행 요청이 아니다.

- 운용 저장소와 원본 BAG, sources/는 읽기 전용으로 취급했다.
- 행사·마감과 추가 실험 가능 범위를 비동기로 질문했다. 응답이 없는 부분은 조건부 계획으로 구분한다.
- 기존 37건 수상 사례 조사와 핵심 로컬 분석·코드, 직접 관련 논문을 교차 검토했다.
- 정확도·독립 평가·최신 선행연구 중복을 중점 검토한다.
- 이 폴더의 보고서·생성기·검증 기록만 최종 산출물로 보존한다.

결과: 8개 후보를 비교하여 조건부 1순위와 단기 대안을 선정했다. 핵심 제안 발췌의 독립 검토 후 방법 차이와 평가 기준을 수정했다. HTML 생성·링크 검증·첫 화면 시각 검증을 완료했다. 장비 접근과 실험 성능은 미확인으로 남겼다. Git HEAD/상태 비교 결과는 final-state.json에 기록했다.
