# 문서 검증 기록

- 범위: 연구 주제 선정 문서. 저장소 전체 감사나 새 BAG 재처리·실기 시험은 수행하지 않았다.
- factchk: 보고서의 직접 관련 문헌 10개와 공식 행사·수상 자료를 대조. 본문 검토와 초록/저자 자료 검토를 보고서에 구분했다.
- mandela: 추정 입력과 평가 정답 공유, 동일 BAG 조정, 구성요소 제거의 혼재를 점검했다. 평가의 완료 조건을 제안 방법의 신뢰도 규칙에서 분리했다.
- sip/shower: 핵심 선정·방법·평가·중단 기준 발췌를 맥락 없는 별도 검토자에게 제공했다. 전체 보고서 외부 검토는 아니다. 초기 needs work → 관측별 판단 예, 외부 완료 기준, 예비 장비 조건, 오판 0의 해석을 수정 → 수정문 stands on its own. 이는 기술적 우월성 검증을 뜻하지 않는다.
- ssotize 읽기 전용: 수상 조사, tracking baseline, 구현 보고서, 최신 commissioning 결과의 수치를 대조. 초기 4초 결과와 전체 기록 평가가 다름을 명시했다. 과거 문서는 변경하지 않고 출처를 연결했다.
- re0: 결과/제안/미확인을 구분하고 제안의 구체적 차이와 주제 전환 조건을 해당 본문에 반영했다.
- detool: 이 문서는 TRON의 구체적 환경과 출처를 다루며 도구 독립성을 주장하지 않아 적용하지 않았다.
- HTML: 11개 본문 섹션, 10개 표, 로컬 링크 7개와 내부 목차 링크 검증. 렌더링한 첫 화면을 육안 확인했다. 전체 페이지 모든 화면 크기의 시각 검증은 아니다.
- 생성 과정의 초기 mistune API 불일치는 설치된 0.8.4 API에 맞춰 해결했다. 브라우저 첫 실행은 sandbox에서 실패했고, 읽기 전용 렌더링 재시도는 성공했다.
- 두 임시 브라우저 프로필 /tmp/tron-topic-html-knjfxn82, /tmp/tron-topic-html-yecv_ry5는 제거했다. 브라우저 프로세스 그룹을 종료했다. 로봇/ROS 프로세스는 실행하지 않았다.
- 보존물: REPORT.md, report.html, build_report.py, report-preview.png와 출처 대조·검증 기록. 원본 BAG/운용 코드/sources는 변경하지 않았다.
