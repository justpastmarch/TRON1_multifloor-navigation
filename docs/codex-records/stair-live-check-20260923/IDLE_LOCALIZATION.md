# 0 명령 중 미세 이동과 AMCL 분포

2026-09-23 08:27:43~08:28:18 KST의 읽기 전용 점검이다. 사용자는 RViz 위치·방향이 맞게 보이며, TRON은 하드웨어 특성상 0 명령 중에도 전후 이동하거나 회전한다고 확인했다. 0 명령을 물리적 정지의 근거로 삼지 않는다. 운영 노드·설정·소유권은 변경하지 않았고 이동 목표나 보정 명령을 보내지 않았다.

**판정: AMCL의 넓은 위치 후보 분포와 센서 간 상대 변화 차이는 확인됐다. 실제 이동량의 정답과 AMCL 설정 변경의 개선 효과는 미확인이다.** 이것은 전체 저장소 감사나 계단 주행 완료 판정이 아니다.

## 운동 모델에서 확인한 증폭 가능성

**OBSERVED, upstream.** 현재 파라미터는 `odom_model_type=diff`, `odom_alpha1~5=0.2`, 갱신 기준 `update_min_d=0.1m`, `update_min_a=0.1rad`다. repository launch가 거리·각도 갱신 기준을 지정하며, 모델과 alpha는 이 launch에서 별도 지정하지 않는다. ROS Noetic의 [diff 모델 소스](https://github.com/ros-planning/navigation/blob/noetic-devel/amcl/src/amcl/sensors/amcl_odom.cpp#L154-L198)는 이동 방향과 기존 몸체 방향 차이를 첫 회전으로, 남은 방향 변화를 두 번째 회전으로 분해한다. 그 각도를 잡음 계산에 사용한다. [난수 함수](https://github.com/ros-planning/navigation/blob/noetic-devel/amcl/src/amcl/pf/pf_pdf.c#L122-L139)의 인자는 표준편차다. 갱신 조건과 입자 발행은 [AMCL 노드 소스](https://github.com/ros-planning/navigation/blob/noetic-devel/amcl/src/amcl_node.cpp#L1093-L1259)에서 확인했다.

**OBSERVED, 계산 재구성.** 두 AMCL scan 시각의 기록된 `odom→base_Link` TF를 보간한 순변화는 11.774cm와 -1.494°다. 위 공식에 대입하면 첫 회전 -81.303°, 두 번째 회전 +79.808°, 이동 잡음 표준편차 **0.794m**가 계산된다. 이는 모델이 만든 수치이며 실제 로봇의 회전·이동 오차가 아니다. [입력과 계산 결과](idle-motion-model-reconstruction.json). 정확한 필터 내부 갱신 경계와 입자별 난수는 계측하지 않았으므로 실제 입자 생성 과정을 재현했다고 주장하지 않는다.

**INFERRED · Safety S2 / Mobility M2, 잠정.** 기록된 측방향 odom 변화가 현재 diff 모델의 큰 회전 분해와 결합하는 것이 넓은 입자 분포의 유력한 기여 요인이다. 단독 원인으로 확정하지 않았으며 지도·scan 적합도도 확인해야 한다. S2는 NAV 위치 판단 저하가 충돌 여유를 줄일 가능성, M2는 NAV 반복성이 저하될 가능성을 뜻한다. 이번에 충돌이나 주행 실패를 관찰한 것은 아니다.

## 적용 원칙과 다음 검증

실제 미세 이동은 측위가 계속 따라가야 한다. 화살표를 숨기거나, 0 명령 중 위치를 고정하거나, 관측된 횡이동을 근거 없이 0으로 만드는 방식을 해결로 간주하지 않는다. 작은 흔들림만으로 전체 주행을 막는 새 gate도 추가하지 않았다.

기존 AMCL 노드를 유지하면서 동일 BAG의 운동 모델·잡음 계수 후보를 비교하는 것이 다음 단계다. 작은 입자 분포만을 점수로 삼지 않고 scan과 지도 정합, 위치 연속성, 실제 주행 구간도 함께 확인해야 한다. 특히 `diff-corrected`로 이름만 바꾸면 해결된다고 가정하지 않는다. 미세 움직임 추적과 대기 지점의 능동 위치 유지는 별개의 기능이다. 후자는 기존 제어 소유권에서 검증해야 하며 이번 점검으로 구현 완료되었다고 주장하지 않는다.

**UNVERIFIED.** 독립 실측 기준, 파라미터 비교 재생, 변경 후 실제 NAV, 계단 자세 유지와 완주. `configured=true`와 센서 기동 완료는 이 항목들을 대신하지 않는다.

검토에는 sip의 shower, factchk, mandela, ssotize 감사 절차를 적용했다. 독립 cold-read에서 '오차 확대'를 확정하는 표현과 '입자 중심'의 모호함을 지적받아 실제 오차·기여 요인·평균 위치를 구분했다. 기존 RUNBOOK 및 LIVE_READINESS와 '0은 물리적 위치 유지가 아니다', 'configured는 실기 완료가 아니다'가 일치한다. 문서 통합이나 운영 파일 수정은 하지 않았다. re0는 관측·추론·다음 검증 순서로 이 문서를 정리하는 데 사용했으며, 이 기록은 현장 설치를 특정하므로 detool의 이식성 검사는 적용하지 않았다.

관측 도구의 ROS 로그와 프로세스는 정리한다. JSON, 본 문서와 읽기 전용 관측 스크립트는 재현용 증거로 보존한다. 이전부터 실행 중인 센서·Supervisor·RViz·자동 BAG는 운영 세션으로 유지한다. 최종 정리 및 Git 비교는 [idle-cleanup.json](idle-cleanup.json)에 기록한다.
