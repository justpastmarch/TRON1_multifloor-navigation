# 원문 치수 복구 후 고정 형상 비교

2026-09-23. 사용자가 이미 제공한 수치를 이 작업이 놓쳤다. 2026-08-21/09-04/09-11의 원문과 기존 시뮬레이션 site 파일을 읽어 복구했고, 실제 저장소 보고서와 현재 적용 안내를 정정했다. 치수 재입력/응답 대기는 해제했다.

원문: 3→4 및 4→5는 9단–계단참–10단. 계단 폭 1.23m, 단 깊이 0.28m, 단 높이 0.17m. 계단참 가로 2.70m, 깊이 1.48m. 5→RF의 10+9+2단은 별도 경로다. 원문 발췌는 user-measurement-sources.json, 해시가 있는 기존 설정 연결은 recovered-site.json에 보존했다.

## 이번에 이어서 수행한 오프라인 작업

- 원래 BAG에서 102101의 100개 scan/925851점, 105713의 68개 scan/686370점을 동결된 LiDAR pose로 다시 모았다. 센서 장착 회전·translation·tracking 코어를 바꾸지 않았다.
- 기존 simulation world의 계단 직사각형 배치 규약과 사용자 치수로 하나의 동일 형상을 만들었다. 첫 상승 1.53m, 둘째 상승 1.70m, 합계 3.23m는 입력값의 계산이다.
- 각 BAG의 원점 차이를 x/y/z/yaw 네 값으로만 정합했다. 치수·scale·중력 roll/pitch는 최적화하지 않았다. 정합에는 전체 기록의 미래 scan도 들어간다. 따라서 이는 INFERRED 오프라인 정합이며 실시간 진입 측위 검증이 아니다.
- 동일한 footprint 45×45cm, 마진 2cm+기존 anchor 오차 가정 10cm, 속도/가속 한계로 현재 Supervisor 정책을 평가했다. 그 결과로 마진·속도·실기 설정을 변경하지 않았다.

## 결과와 한계

102101은 첫 구간 13.6003초에서 SUPPORT_LIMIT. 직전 가정 경로의 13.7993초보다 먼저 중단하므로 개선으로 판정하지 않는다. 이때 현재 몸체는 마진을 포함해 영역 안이지만 예측 이동에서 벗어난다.

105713은 19.5998초에 첫 구간 완료 조건을 충족해 LANDING으로 넘어간다. 다만 다음 관측인 19.7997초에 CORRIDOR_LIMIT. 현재 외곽은 영역 안이지만 여유 9.770cm가 적용 마진 12cm보다 작다. 직전 가정 경로에서는 첫 구간에 남아 22.7998초에 중단했다. 단계 선택에 차이가 생겼지만 전체 통과나 성공률 개선으로 세지 않는다.

고정 모델의 10cm 안 관측점 대응 비율은 약 53.1%/57.3%이고 첫 네 단은 두 BAG 모두 충분히 보이지 않는다. 여러 초기값이 다른 정합 결과로 수렴한다. 이 비율은 가려진 모델 면적도 포함하는 기하 관측률이며 외부 측량에 대한 정확도가 아니다. 후보를 검증된 live anchor나 실기 commissioned route로 활성화하지 않았다.

## 다음 시작점

사용자에게 같은 치수를 다시 물을 필요가 없다. 남은 조사 대상은 (1) 보이는 계단참/상부 모서리로 반복 단 패턴 정합의 모호성을 줄이는 것, (2) 전체 기록을 쓴 오프라인 정합과 시작 시점 센서만 쓴 정합을 구분하는 것, (3) 실제 경계/anchor 오차를 분리해 transition과 margin 차단을 평가하는 것이다. 수동 BAG는 가상 명령에 반응하지 않으므로 중심 보정이나 물리 완주 성능은 별도로 검증한다.
