# 결과 검증 기록

2026-09-21. 분석 스크립트·보고서 검증이며 운용 코드 인수 테스트가 아니다.

- 숫자 검증: 원시 LiDAR 28,983, 표본 5,803, 기록 시각 평가 1,088, 양면/V1/V2=606/769/642. header 대응 1,058, 616/772/648. 알려진 변형 504건 중 464성공. JSON·CSV·보고서 수치를 대조했다.
- 동결 검증: stair_geometry.py 해시가 frozen-method.json과 동일하다. V2와 header 대응은 평가 후의 탐색 진단으로 따로 기록했다. 반례를 삭제하거나 최초 결과를 덮어쓰지 않았다.
- sip/shower: 주변 자료와 의도를 받지 않은 별도 검토자가 보고서 전체를 읽었다. 최초 minor gaps: 시각 대응 분모, 분석 구현/운용 통합 구분, RF 0/3의 원인, 관측 모드 인수 기준. 이를 고치고 측정 header 대응 실험을 추가했다. 수정본 전체 재검토는 stands alone. 마지막 표현 두 건도 수정했다: 증가율 비교 주체 명시, record-header 차이를 검증된 수신 지연으로 단정하지 않음.
- factchk: repository의 직선 단계 각속도 0·odom 기반 phase 판정은 현재 소스에서 확인했다. IMU 계약은 기존 숫자 결과와 설치 드라이버 소스를 재확인했다. 일반 RANSAC 평면 모델은 PCL 공식 문서를 확인해 연결했다. 외부 firmware 동작·실제 균형 개선은 미확인으로 남겼다.
- mandela: 자기 평면 기준의 변형 잔차와 odom 비교는 절대 정확도 근거가 아니다. 같은 계단/라벨러와 평가 후 V2 수정의 독립성 한계를 METHOD.md에 명시했다. 새 외부 측량이 필요하다.
- ssotize read-only: 새로운 수치의 기준은 comparison.json, robustness.json, time-alignment.json이며 표·그림·보고서는 파생 표현이다. 기존 최소 변경 계획의 관측/착지 미검증 상태, 원래 센서 보고서의 IMU/시각 주장은 이번 결과와 충돌하지 않는다. 기존 계획·감사·원본은 변경하지 않았다. 통합/이동/삭제 제안은 실행하지 않았다.
- re0: 첫머리에 실행 완료 범위를 명시하고, 시각 보정 결과를 해당 수치·반례 문단에 반영했다. 실행 이력을 본문 끝에 덧붙여 잘못된 최초 결론을 남기는 방식을 피했다.
- detool: 이 보고서는 특정 ROS 저장소와 센서 기록을 추적하는 기술 증거다. 도구 독립적 이식성을 주장하지 않으므로 생략했다.
- 표시 검증: 네 과학 그림을 직접 시각 검사하고 HTML의 내부 앵커·로컬 자원 링크를 검사했다. Markdown의 표와 HTML은 동일 문서에서 생성했다. 외부 링크를 운영 네트워크 동작으로 실행하지 않았다.
- 원본과 정리: 21원본 size/mtime와 source Git 상태를 전후 대조했다. 상세 cleanup와 보존 산출물 해시는 CLEANUP.json / ARTIFACTS.json에 있다.
