# 계단 주행 복구 구현 기록

Understood as: 앞서 합의한 3→4층 복구 계획의 시작 명령, 경계·좌표 정합, 단계 전환, 연결 시험, 설정·진단·실행 절차를 기존 구조에 구현하고 가능한 오프라인 검증을 수행한다. 실기 관찰이 필요한 항목을 임의로 완료 처리하지 않는다.

기존 working tree를 보존하기 위해 현재 파일 사본에서 수정·검증한 후 원본 해시를 다시 대조해 이번 변경만 적용한다. 새 ROS 노드·전송자·SLAM은 추가하지 않는다. 추적 코어·IMU 보정은 동결한다. 실제 로봇 주행은 시작하지 않는다.

구현 상태: 실제 저장소 28개 파일 변경/추가 적용 및 해시 확인. 기존 Git 상태 항목 전부 보존, HEAD 동일. 단위 135개, pytest 8개, ROS 경계 5개+관찰 1개, 설정 5건, 실제 저장소 핵심 회귀 3개 통과. 임시 artifact/group 27개 제거. 실기 적용 가능한 공통 3→4 경로와 실제 완주는 미완료다.

2026-09-23 정정: 사용자는 이미 2026-08-21에 3→4층 9단–계단참–10단, 2026-09-04에 계단 폭 1.23m·깊이 0.28m·높이 0.17m 및 계단참 2.70×1.48m를 제공했다. 원문과 기존 simulation site 파일을 복구했으므로 같은 치수의 재입력이나 사용자 답변을 기다리지 않는다. [후속 기록](../stair-geometry-recovery-20260923/ANALYSIS.md)에서 이어간다. 동일 형상과 서로 다른 원점으로 두 BAG을 평가했으나 완주 정책 통과는 아니며, 전체 기록으로 맞춘 원점은 실시간 진입 측위 검증이 아니다. 후속 변경은 기존 저장소 docs 내 보고서·안내·근거 파일에만 적용했다.
