# 북서 이후 남서 재방문 우회 수정

2026-10-16. 사용자는 남서→북서→남서→남동→옥상 탈출점 순서를 요청했다.

OBSERVED: 09:29:53 BAG에서 남서(0.476039,-8.048886), 북서(-2.083093,-3.400745) 다음 목표가 북동(5.900059,-3.046832)으로 전송됐다. 임무 피드백도 북동을4개 구간 중 첫 구간으로 표시했다.

원인: photo_tour.yaml의 촬영 순서는 수정됐지만 building_graph.yaml은 기존 단방향 순환 연결이었다. 북서→남서 직행 연결이 없어 BFS가 북동→남동→출구→남서로 우회했다. 남서를 완료했다고 생략한 것이 아니라, 남서에 가기 위한 중간 목표가 잘못된 사용자 의도였다. 이전 답변에서 촬영 목록만 확인하고 전체 L자 이동이라고 설명한 것은 부정확했다.

수정: 기존 그래프에 북서→남서(roof_loop_west_return), 남서→남동(roof_loop_south) NAV 연결만 추가했다. 새 노드나 상태머신은 추가하지 않았다. 물리적 경로는 move_base가 기존 지도에서 계획한다.

검증: 실사용 설정으로 펼친 NAV 목표가 요청된5개 방문과 정확히 일치함을 expanded-plan.json에 기록했다. 기존 촬영 순서 검사에 실제 NAV 목표 전체 비교를 추가했다. 관련244개 테스트 통과. 실주행 완주를 증명하는 결과는 아니다.

적용 시 앞서 대기했던 WALK 무응답 진행과 RF 전진 상한0.21m/s 설정도 함께 반영한다. 서비스 변경은 임무·녹화가 유휴인 것을 확인한 후 수행하며 주행은 자동 시작하지 않는다.

추가 검증: ROOFTOP_TOUR(옥상 순회)와 PHOTO_TOUR(상승 후 촬영)를 각각 실행해 실제 NAV 목표와 촬영 목록이 모두 동일한5개 순서임을 확인했다. 결과는 both-buttons.log.
