# 계단참 도착 시험 후 위치 유지 — v11

정책 `2026-09-28-landing-hold-v11`. 기존 supervisor 내부의 위치 유지와 단일 송신 경로를 사용한다. 새 노드·상위 상태 단계·토픽은 추가하지 않았으며 기존 `/tron/sensor_joy` 구독을 추가했다. 실행 중 프로세스 재시작 및 로봇 주행 명령은 수행하지 않았다.

## 관찰 근거

`stair_20260928_103842_essential.bag`에서 10:40:06.132 시험 종료 후 20.543 첫 수동 입력 전까지 조이스틱 7,180개가 모두 0이고 supervisor 속도 송신 578개도 모두 0이었다. 06.200–20.200의 시작 방향 기준 후진 변위는 LiDAR 56.1cm, 본체 odom 56.3cm였다. 후진 속도 중앙값은 약 4.5cm/s였다. OBSERVED: 0 명령은 위치 유지가 아니며, 기존 시험 종료 경로는 능동 위치 보정을 끈다. 실제 밀림으로 해석하는 것은 INFERRED이고 최초 물리 원인은 UNVERIFIED다. Safety S3 / Mobility M4: 낙상 관찰이 아니라 잠재적 계단 경계 이탈 및 위치 유지 실패의 우선순위다.

## 동작

`LANDING`을 목표로 한 시험이 정상적으로 목표에 도달하면, 신선한 LiDAR에서 측정한 현재 몸체 위치와 방향을 고정 기준으로 잡는다. 다음 회전 경유점으로 이동하는 기능이 아니다. `test_status.state`는 `LANDING_HOLD`, 제어 debug는 `landing_position_hold: true`가 된다. STAIR 모드는 유지한다. 시험 결과는 기존과 같이 층 도착 성공을 뜻하지 않으며 결과 설명에 `landing position hold active`가 포함된다.

작은 변위부터 기존 위치/속도 PD 제어로 보정한다. 10cm 이상 밀릴 때까지 기다리지 않는다. 전진·후진 크기는 기존 `hold_v`(현재 내부 입력 0.06) 이하이며 상승 입력 0.55로 전환하지 않는다. 조향 상한과 경로검사는 유지한다. 지속되는 외란을 실제로 이길 수 있는 입력 크기인지는 실측이 필요하다.

허용 경로는 계단참 다각형으로 한정한다. 접근 단계의 계단+계단참 합집합은 유지 중 사용하지 않는다. 시작 때 도착 높이와 자세를 확인하며, 유지 중에는 포착한 높이 대비 기존 높이 허용차를 검사한다. 센서/epoch/자세/경로 오류는 0 명령과 기존 제어권 인계 경로로 전환하며 자동으로 유지 동작을 되살리지 않는다. 새로운 임계값으로 주행 중 상승을 차단하는 변경은 아니다.

조이스틱 축 또는 버튼 입력 시 즉시 보정 명령을 해제한다. 수신 시각 기준 0.5초 넘게 조이스틱 피드백이 없으면 같은 방식으로 해제한다. 이는 이미 수행 중인 주행에 추가한 gate가 아니라, 무인 상태로 계속되는 시험 종료 후 보정이 조종기 개입을 놓치지 않게 하는 조건이다. 정상 무조작 BAG의 최대 수신 간격은 약 0.096초였다. 조이스틱이 다시 0이 되어도 자동 재개하지 않는다. 기존 `release_arrival_hold` 서비스로 명시적 해제도 가능하며, 다음 시험을 시작하면 이전 유지 제어를 먼저 제거한다. 속도 0은 물리적 정지 보장이 아니다.
