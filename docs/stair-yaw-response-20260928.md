# 계단 상승 조향 응답 수정 — v10

정책: `2026-09-28-yaw-response-v10`. 기존 stair supervisor 내부 수정이다. 새 노드·상위 단계·토픽을 추가하지 않았다. 로봇 주행 명령 및 실행 중 스택 재시작은 하지 않았다. 기존 미커밋 변경을 보존했다.

## 근거

2026-09-28 10:45:43 essential BAG의 세 번째 시도는 조이스틱 입력 없이 큰 회전을 기록했다. 센서 시각 10:49:03.000–03.200의 LiDAR yaw 변화 −21.65°, 본체 odom −24.33°, 원시 IMU Z축 적분 −22.04°가 부합한다. 서로 공유하는 추정 입력 및 기울기 영향이 있으므로 완전히 독립적인 절대 yaw 검증은 아니다. 급회전의 최초 물리 원인은 미확정이다.

디버그 수신 시각 10:49:03.100에는 자이로 보정 heading이 +0.5°인데 내부 조향은 −0.0700, 03.186에는 heading −9.5°인데 조향 −0.0413이었다. 이는 명령 기록이며 모터의 실제 적용 승인이나 물리 회전속도가 아니다.

## 적용한 변경

- **OBSERVED, Safety S3 / Mobility M4, TUNE:** 수신된 최근 IMU로 기울어진 몸체 X축의 heading 미분을 계산한다. IMU→LiDAR→몸체 외부 보정을 사용하고 센서 Z축을 그대로 yawrate로 취급하지 않는다. 최근 약 40ms 평균, 미래 샘플 제외, 0.12초보다 오래된 rate에는 감쇠를 적용하지 않는다. heading/횡오차 제어에 `-Kd*yawrate`를 더하되 기여량을 제한한다.
- **OBSERVED, Safety S3 / Mobility M4, TUNE:** 조향을 중립으로 줄이는 변화율과 반대 조향을 키우는 변화율을 분리한다. 중립 도달에 사용한 시간을 차감한 나머지 시간에만 반대 방향 증가를 허용한다. 평지 단계 및 두 번째 상승 전 정렬에는 기존 제한을 사용한다.
- **OBSERVED, Safety S2 / Mobility M3, TUNE:** 횡오차가 만드는 중앙 복귀 목표각의 크기를 제한한다. 목표 위치나 측위 pose를 변경하지 않는다.
- **OBSERVED, Safety S2 / Mobility M4, UNVERIFIED:** `flight_recovery_w`를 명시한 시험 설정에만 제한된 회복 조향을 허용한다. 새 관측으로 시작하고 실제 출력값에서 slew를 적용하며, heading 개선과 두 heading 가설의 footprint 경로를 검사한다. 대기만으로 가상의 조향을 누적하지 않는다. 동일 관측에서의 유지도 경로·신선도·예산을 재검사한다. 중립 요구·단절·epoch 변경·예산 초과는 덮어쓰지 않는다. **운영 YAML에는 이 옵션이 없으므로 비활성화다.** 계단 위 제자리 보정의 효과가 측정되지 않았기 때문이다.
- **OBSERVED, Safety S3 / Mobility M4, UNVERIFIED:** `measured_motion_preview`에 관측 속도에서 출발하는 짧은 예측을 진단용으로 추가했다. 관측 시각과 용도를 함께 출력한다. **후보 허용 판단은 아직 기존 명령 크기 모델을 사용한다.** 측정되지 않은 명령→물리 속도 관계를 보정 완료로 취급하지 않았다.

S0–S4는 잠재적 안전 영향, M0–M4는 주행 영향의 우선순위이며 M4는 임무 중단이다. 실제 낙상이나 이탈을 관찰했다는 의미는 아니다. KEEP 판정은 하지 않았다.

## 초기 시험 파라미터

정확한 값은 [운영 YAML](../src/stair_supervisor/config/stair_lidar_3f_4f_test.yaml)이 기준이다. 추가값은 실장비 보정 완료값이 아닌 제한된 초기 시험값이다.

| 설정 | 값 | 역할 |
|---|---:|---|
| flight_yaw_kd | 0.06 | 회전속도 감쇠 계수 |
| flight_damping_max_w | 0.05 | 감쇠의 내부 조향 기여 상한 |
| flight_gyro_rate_max_age | 0.12초 | 감쇠에 사용할 rate의 신선도 |
| flight_capture_angle | 약 10° | 횡오차에서 만드는 복귀 목표각 상한 |
| flight_neutral_alpha | 0.9 | 기존 조향을 중립으로 줄이는 변화율 |

상승 내부 전진 0.55, 조향 상한 0.2, 반대 조향 증가율 0.3, 계단참 저속은 유지했다. 내부 입력과 실제 m/s·rad/s 응답은 구분한다. 0 명령은 물리적 자세 유지를 보증하지 않는다.

## 검증과 한계

전체 관련 회귀시험 183개 통과 후, 비단위 외부 보정 행렬·복구 중립/단절 시험을 강화하고 영향받는 시험 78개가 모두 통과했다. 읽기 전용 설정 검사는 `configured: true`, 로봇 송신 0건을 반환했다. 독립 코드 검토에서 확정적 결함이 발견되지는 않았으며 실장비 효과를 검증한 것은 아니다.

동일 BAG 상태에서 실제 직전 명령을 시작값으로 삼아 새 조향 계산과 slew를 한 단계씩 비교했다. 세 번째 급회전 구간 03.100의 계산값은 기존 −0.0700에서 약 0, 03.186은 −0.0413에서 +0.0025로 바뀐다. **이 비교는 전체 후보 경로검사를 거친 실제 송신 결과도, 새 명령으로 움직인 폐루프 궤적도 아니다.** 관측을 고정한 조향 계산 비교이며 완주율·안전성 증거로 사용하지 않는다.

다음 단계는 실행 중 프로세스를 v10으로 다시 올린 뒤 제한된 조향 응답을 측정하고 첫 상승을 확인하는 것이다. 계단 위 회복 조향과 물리 응답 기반 후보 모델은 별도 측정 없이는 활성화/교체하지 않는다. 그 두 항목까지 근본 해결이 완료됐다고 주장하지 않는다.
