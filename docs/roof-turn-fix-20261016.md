## 사용자 지정 순서 반영

2차 상승 → 중앙 반경35cm 접근 → 제자리 우회전 → 두 단 진입. 중앙은 기존 측량 경로의 (-0.46,1.47)이며 정확한 한 점 정착을 요구하지 않는다. 회전 공간만 확보되면 임의 깊이에서 회전을 시작하던 방식에 중앙 근처 조건을 추가했다. 중앙 접근에는 기존 저속 위치 보정, 회전에는 기존 방향 제어를 사용한다. 두 초기 자세의 이상적 주행 모델에서 중앙 접근→회전→최종 상승 전이가 확인됐다. 실제 지도가 물리적 중앙을 정확하게 표현하는지는 실주행 대조가 필요하다.

최종 계단 회귀436개 통과. 신규 회귀는 중앙영역 밖에서는 회전을 시작하지 않음, 중앙 근처에서는 정밀 정착 없이 회전 시작, 기록된 진입 자세의 저속 보정과 상승 입력0.55 전환을 확인한다. UI JavaScript 구문 검사 통과.
