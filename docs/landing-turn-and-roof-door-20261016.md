## 수정

- 회전 공간 추가 여유만 1cm. 실제 몸체 지지 여유와 도착 영역 여유 3cm는 유지했다.
- 다음 회전점을 벽 가장자리로 재설정하지 않도록 제한했다.
- 두 번째 계단의 사용 가능한 폭에 진입하고 회전 공간이 확보되면 두 번째 회전을 시작한다. 정확한 한 점을 계속 쫓지 않는다.
- 공간이 부족한데 목표점에 가깝다는 이유만으로 보정을 0으로 만들지 않는다. 안쪽을 향하도록 조향하고, 회전 중에도 가까운 경계의 안쪽 방향으로 보정한다.
- 기존 상태머신과 노드 구성 유지. 계단참 속도 상한 0.195, 두 번째 상승 진입 시 기존 상승 입력 0.55를 사용한다.
- UI 모든 탭의 상단에 **옥상 문 열기 · 60초** 버튼 추가. 현재 층·임무·제어권과 별개로 RF 요청을 보낸다. 요청 완료 뒤 재클릭하면 60초를 갱신한다. 응답 대기 중 중복 요청만 잠시 차단한다.
