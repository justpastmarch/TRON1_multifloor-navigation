# 옥상 왕복 촬영 경로 변경 — 2026-10-16

- 순서: roof_loop_sw → roof_loop_nw → roof_loop_sw → stair_rf_landing.
- 각 방문마다 새 RGB 사진 저장 및 메일 요청. 첫 지점 재방문도 별도 방문 번호로 처리한다. 마지막 옥상 출구에서도 촬영하고 대기하며, 계단 하강은 시작하지 않는다.
- 촬영 지점 도착 반경: 0.35m → 0.60m. 방향 오차: 30도 → 사용자 지정 ±50도. 기존 최신 위치 및 도착 지속 확인은 유지한다.
- 위치 유지 활성화가 일반 NAV에 5cm/4.6도 정밀 도착을 강요하던 연결을 해제했다. 일반 NAV는 기존 기본값 25cm/30도, 촬영 순회는 위 별도 허용 범위를 사용한다. 옥상 출구도 촬영 순회 허용 범위를 적용한다.
- NAV 회전 상한: 0.8 → 1.2rad/s. 제자리 최소 회전 입력: 0.25 → 0.30rad/s. 계단 주행 속도는 변경하지 않는다.
- 이전 네 지점 순회 기록과 새 경로가 다르면 새 순회를 생성하고 기존 기록을 보관한다. 같은 경로 재시도는 방문 번호별 촬영 완료 기록으로 이어간다.
- UI의 경로 설명·목적지 선택도 새 순서로 변경했다.

실제 로봇의 도착·촬영 성공을 강제하지 않는다. 넓어진 허용 범위 안의 위치와 방향을 새 센서 관측으로 확인해야 한다. 변경 후 실주행 성공은 별도 확인이 필요하다.
