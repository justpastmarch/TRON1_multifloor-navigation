한 번 주행하고, 2D·3D 지도를 만드세요

2D는 MID360 scan과 바퀴 odom으로 실시간 작성합니다. 원본 LiDAR·IMU는 미니 PC에 따로 녹화해 작성 종료 후 3D 지도를 만듭니다. 로봇 이동은 물리 조종기로 하세요.

준비 중

지도 저장은 작성 중 언제든 여러 번 할 수 있고, 작성 종료는 기록(BAG)을 마감합니다. 지도 품질은 실측으로 확인해야 합니다.

실시간 지도

사진 메일

현재 카메라 사진 한 장을 찍어 바로 메일로 보냅니다. 수신 주소와 발송 기록은 주행 UI와 같습니다. 사진을 찍는 순간에만 영상을 받습니다.

확인 중

지도 만들기 · 2D와 3D

작성 종료 후 같은 기록으로 2D(SLAM Toolbox 재생)를 다시 만들고, 그 경로를 따라 원본 LiDAR 점을 쌓아 3D 지도를 만듭니다. 3D 높이와 기울기는 평평한 바닥을 가정한 근사입니다.
