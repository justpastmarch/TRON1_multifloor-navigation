실시간 지도

저장된 장소·지도

미리보기와 다운로드는 현재 지도·주행 설정을 바꾸지 않습니다. SLAM Toolbox 그래프가 저장된 버전은 첫 기록 위치에서 이어서 작성할 수 있습니다.

같은 기록으로 A/B 비교

SLAM Toolbox와 Gmapping에 같은 scan·odom·TF를 재생합니다. 비교는 별도 ROS Master에서 순서대로 실행합니다. 넓이·처리 시간은 정확도 점수가 아닙니다. 각 지도는 관측 영역에 맞춰 표시하며 화면의 위치·방향은 서로 다를 수 있습니다.

기존 주행 BAG으로 검증

평지에서 기록한 BAG을 선택하세요. 계단·다른 층이 섞인 기록은 2D 매핑 품질 평가에 적합하지 않습니다.
