직접 조작

잡고 있는 동안 수동 명령을 우선 송신합니다.

위·아래 끝은 전후진 ±1, 좌·우 끝은 회전 ±1입니다. 위 전진 · 왼쪽 좌회전
키보드 ↑ 전진 · ↓ 후진 · ← 좌회전 · → 우회전
방향키를 놓으면 수동 입력을 해제합니다. 두 키를 함께 누르면 곡선 주행합니다.

계단 임무 상태를 기다립니다.

중단 후 같은 단계에서 재개하거나, 수동 이동 후 다음 단계를 선택합니다. 앞선 구간은 사용자가 완료했다고 기록합니다. 층 도착 확인과 남은 미션은 기존 절차를 따릅니다.

연결 상태를 기다립니다.
전진 0% · 회전 0%

손을 놓거나 입력이 0.35초 동안 없으면 수동 입력을 해제합니다.
최신 자동 명령이 있으면 자동 주행을 계속하고, 없으면 속도 0을 보냅니다.
전체 정지는 상단 버튼을 사용하세요.

취소는 기존 상태머신에 요청합니다. 속도 0이나 임무 종료가 로봇의 물리적 자세 유지를 보장하지는 않습니다.
